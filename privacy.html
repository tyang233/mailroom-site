Mailroom Privacy Policy

Last updated: October 17, 2026

Who uses Mailroom

Mailroom is a personal tool used only by its developer, on his own computer, with his own email accounts. It is not offered to the public.

What data it accesses

With the account owner's consent through Google OAuth, Mailroom uses the Gmail API scope https://www.googleapis.com/auth/gmail.modify to:

  • read messages and labels so they can be searched locally;
  • create drafts, which the owner reviews and sends himself;
  • add a label to messages it judges to be likely phishing.

Mailroom never sends email, and never deletes or moves messages.

Where data is stored

Email content is stored only in a local database on the owner's computer. OAuth tokens are stored in the macOS Keychain. No email data is sent to the developer's servers or to any third party; Mailroom has no servers.

Sharing

Mailroom does not sell, share or transfer Google user data. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local Mailroom folder removes all stored mail data.
